# C Programming Basics & Practice

A collection of C programming exercises, beginner-friendly programs, and coding practice developed while learning the C language. This repository covers fundamental programming concepts, mathematical operations, operators, and problem-solving techniques.

## Topics Covered

- **Fundamentals:** Hello World, variables, data types, input/output operations, and basic syntax.
- **Operators:** Arithmetic operators, increment, decrement, bitwise AND, complement, and left shift operators.
- **Mathematical Programs:** Area and circumference of circles, area of square and triangle, temperature conversion, and mathematical calculations.
- **Number Programs:** Factorial, prime number, perfect number, odd/even numbers, and leap year checking.
- **Control Statements:** Conditional statements, loops, and logical operations.
- **Arrays & Strings:** Basic array operations and character conversion (uppercase to lowercase).
- **Functions & Recursion:** Function implementation and recursive factorial calculation.
- **Pointers & Memory:** Dynamic memory allocation using `malloc()`.
- **Structures:** Working with structures and user-defined data types.
- **Problem Solving:** Number swapping, multiplication tables, star patterns, salary calculation, and other programming exercises.

## Getting Started

To explore the code locally, clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/C-Programming.git
```

Navigate to the project directory:

```bash
cd C-Programming
```

## Running C Programs

Compile any C program using GCC:

```bash
gcc main.c -o main
```

Run the compiled program:

**Windows:**

```bash
main.exe
```

**Linux / macOS:**

```bash
./main
```
